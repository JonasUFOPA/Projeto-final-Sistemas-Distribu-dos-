Meu projeto final de Sistemas Distribuídos consiste no desenvolvimento de um sistema de mensagens em rede local, semelhante a um chat, utilizando Python e a arquitetura cliente-servidor. Inicialmente, implementei a comunicação básica com sockets TCP. Depois, acrescentei comunicação contínua, utilização de threads e suporte a múltiplos clientes conectados simultaneamente. Também desenvolvi funcionalidades de identificação dos usuários, distribuição de mensagens, notificação de entrada e saída, listagem dos usuários conectados e encerramento da conexão por meio de comandos. O servidor utiliza a porta 5000 e fica responsável por receber as mensagens e encaminhá-las aos demais participantes. Os clientes se conectam ao servidor por meio do endereço IP do computador que o executa. Até agora, desenvolvi o código e iniciei os testes em dois computadores físicos. Confirmei que o servidor está escutando na porta configurada e que o acesso local funciona. Entretanto, a conexão entre os dois computadores ainda apresenta timeout. Estou investigando possíveis restrições do firewall ou da rede utilizada, pois não tenho permissão administrativa para alterar algumas configurações do Windows.
